# realchrisolin.audio

Omarchy bar Audio widget, cloned from `omarchy.audio`.

Plugin id: `realchrisolin.audio`  
Live path: `~/.config/omarchy/plugins/realchrisolin.audio`

Keeps `ipcTarget: omarchy.audio` so volume IPC stays on this widget.

Adds a **Cancel echo from display** toggle while Miracast is the output
(`miracast-ctl set-echo-cancel`, settings `echoCancelMiracast`).
